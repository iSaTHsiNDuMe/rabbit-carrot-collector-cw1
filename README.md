# Rabbit Survival

CW1 Unity project snapshot for Group 02. Open the Unity project folder in Unity Hub using Unity **6000.6.4f1**, then open `Assets/Scenes/RabbitSurvivalLEGO.unity` and press Play.

- **WASD** moves the rabbit and **Space** jumps.
- **C** locks or frees the mouse for camera rotation. **Esc** frees the cursor.
- Enter any bush to show the hidden state. The Student 3 walk preview button appears at the demo clearing.

The scene includes the LEGO map, the five carrot placements, six hideouts, both hunters, the bridge, and the cave reunion zone. The walk preview uses a placeholder because the lecturer's `LegoWalk.fbx` was unavailable. The Member 4 update adds hunter patrols, a key-triggered cave wall, a reunion trigger, and a walk button for the white rabbit.

The environment and brick-style character assets were produced with AI-assisted Unity editor tooling.
